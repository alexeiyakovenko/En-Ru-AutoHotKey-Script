Работает по Alt+Shift (в любом порядке нажатия).

Решает проблему переключения языков в Windows 11. Вам понадобится AutoHotkey v2.0: https://github.com/AutoHotkey/AutoHotkey/tree/alpha

Переключение языка происходит не только в самой системе, но и при сохранении/переименовании файлов, создании/переименовании папок.
